共同点：没有人独立验证过"Agent 到底做了什么"。OpenWorkProof 补上这一层。

交付物：一份《Agent 工作验证报告》

1. 三态结论

一次交付 → 一份结论： VERIFIED（证据链完整且一致）、 REFUTED（证据被推翻，如负控未按注册原因失败）、 UNKNOWN（证据不足——安全的结论，不是故障）。

2. 证据摘要

授权链、执行范围、合格人口（选了多少 / 合格多少）、负控结果、
源码 revision、参数、manifest digest——全部签名、只追加、不可篡改。

3. 可重放包

一份 delivery package + 一条命令，客户在本地离线复现： verify_delivery_package。不依赖我们的服务器、不依赖网络。

4. 独立验证（高风险工作）

两个不同信任域的 Verifier 各自独立执行、独立签名，结果逐字段交叉收敛； 任一承载结论的字段不一致 → 拒绝形成决策。

为什么可以信

  • 5 分钟挑战：我们只改证据链里的一个字节，验证器仍能抓出它——你自己跑一遍。
  • 协议开源：全部代码公开，Apache-2.0，冻结 Schema 0.1–0.5。
  • 离线可重放：客户在任何一台干净机器上复现，不信任任何一方。
