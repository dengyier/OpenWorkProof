# DESIGN — OpenWorkProof 参赛方案

## 风格：科技 · 可信 · 证据驱动（通用设计原则，非预设分支）

### 画布与母版（1280×720）
- A 标题块：0–120px（padding 20），主标题 36px bold
- B 内容区：120–660px（540px 可用）
- C 页脚条：660–720px（padding 20），左项目名 / 右页码 NN / 09，14px 灰
- 页面 padding：上下 20、左右 72

### 色彩系统（≤4 hex）
| 角色 | Hex | 用途 |
|---|---|---|
| 背景 | `#FFFFFF` | 全局背景 |
| 主色 | `#0F172A`（深蓝黑） | 标题、大色块、页脚 |
| 辅色 | `#3B82F6`（蓝） | 卡片头、SVG 架构主色、分隔线 |
| 强调色 | `#06B6D4`（青） | 巨型数字、焦点标注、CTA |

渐变：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)` 用于封面主色块与数据卡头部。
半透明：卡片叠层 `rgba(59,130,246,0.08)`；大数字底层 `opacity 0.15`。

### 色彩面积分配
- Hero 页（01/05）：主色 ≤55%，辅色 ≤25%，强调 ≤15%（封面青蓝块）
- Supporting 页：主色 ≤40%（标题/大色块），辅色 ≤20%（卡片），强调 ≤5%（仅数据锚点）
- 至少 2 页（01 封面、05 AgentTeams）与其他页显著不同

- 常规页留白 ≤25%；hero 页围绕锚点留白
