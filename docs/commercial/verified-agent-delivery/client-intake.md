# 客户准入与任务冻结模板（Client Intake）

本模板用于在开工前冻结一次交付的验收口径。任何一项无法填写的任务都不得开工。

## 必填项（缺任何一项不得开工）

### 1. 真实仓库或脱敏仓库

- 仓库地址 / 脱敏镜像；
- 源 revision（完整 commit SHA）；
- 可执行测试入口与固定测试源；
- 允许工具、允许路径、必选产物与排除项。

### 2. 任务单 / SOW 外部引用

- 付款主体（谁付）；
- 付费原因（为什么付）；
- 任务金额区间与 OWP 服务费；
- 期限与交付范围。

### 3. 双方冻结的 SubjectClaim 与 WorkOrder

- 验收口径在执行前冻结；
- WorkOrder 绑定六角色身份（含独立 Acceptor）。

### 4. 独立 Verifier

- 与交付团队独立的密钥、上下文和执行环境；
- 冻结的 Verification Profile、范围与环境指纹。

### 5. 客户控制的独立 Customer Acceptor

- Acceptor 密钥独立于交付团队与 Verifier；
- 由客户控制签署 ACCEPTED / REJECTED。

### 6. 冻结的验收条件与排除项

- 验收条件、必选产物、允许工具、测试与排除项必须写成可执行、可复核的条款；
- 排除项明确列出，不得在执行中追加未冻结条件。

## 停止条件

- 缺任务单 / SOW 引用或付款主体：不得开工；
- 缺冻结验收口径、独立 Verifier 或独立 Acceptor：不得开工；
- 执行中出现验证者分歧或环境不完整：停止并记录 `UNKNOWN`；
- 客户合法拒绝：记录 `REJECTED`，不得渲染成成功；
- 未取得外部付款凭证：只记录 `READY_FOR_SETTLEMENT_REVIEW`。

本模板不构成法律文件，不构成付款担保，不承诺客户必然接受。
