# OpenWorkProof 1.2.0

OpenWorkProof 1.2.0 packages the completed Verification Integrity v0.5 work for
Python, CLI, and MCP distribution.

## Version boundaries

- `1.2.0` is the software distribution and MCP Server version.
- `0.5` is the newest protocol schema family.
- Protocol schemas v0.1 through v0.5 remain packaged for explicit versioned
  verification.

## Highlights

- freezes the eligible population before selection;
- binds selector inputs and per-rule witnesses to the signed verification
  record;
- distinguishes negative controls that failed for the registered reason from
  controls that merely failed;
- preserves fail-closed `VERIFIED / UNKNOWN / REFUTED` semantics across Python,
  CLI, Service, Delivery Package, and MCP read-only validation surfaces;
- retains 21 MCP tools and offline third-party verification;
- corrects package and MCP metadata to match the repository's Apache-2.0
  license.

## Evidence boundary

`READY_FOR_ACCEPTANCE` means the evidence package meets protocol conditions for
entering acceptance. It does not establish customer adoption, a paid SOW,
deposit, upstream adoption, production deployment, customer acceptance,
payment, fund release, or automatic settlement. Those states remain
`not_evidenced` until supported by independent external evidence.
